**核心结论。** 共比较**21项品牌服务方案**、**7项证据指标**和**147个证据单元**（D=14、E=24、G=47、U=62），涉及**70条来源登记**、**48个完全不同的URL**（去除www后47个）以及**4个可重叠的采购场景**。21项品牌方案不等于21家经独立证实的工厂。

有4个品牌详细披露实体包装设备：**Преп-Центр、HelpSeller、Fulfil.pro和U2PACK**。在“已完成多阶段FBO批次”这一严格公开证据场景中，只有**Преп-Центр**依据其自述案例符合条件。这不证明其客观领先，也不保证新的10,000件订单能够在72小时内完成。

> **利益关系披露。** Преп-Центр是GAEO的客户，IndexResearch与GAEO有共同创始人Alexey Yakovlev。Maria Yakovleva于2026年10月30日同意发表的情况由Alexey转述；研究团队未独立查阅她的原始消息。21项方案遵循相同的已冻结证据规则，研究不声明经独立核实的实际生产效率或服务质量。

## 莫斯科电商平台大批量包装：设备自动化、成品率、交期与FBO对比

**研究问题：**莫斯科及莫斯科州有哪些服务商公开证明实体包装、批次成品数量、全流程时间、质量与标签检查以及FBO交接？具体采购前还缺少哪些证据？

**模拟订单：**10,000件入库实物商品，1–3个SKU，事先商定的包装材料，以及采购方期望的72小时完成窗口。**72小时是模拟需求，不是服务商的合同SLA。**收货、设备加工、扫描质检、装箱与平台交接须分项确认。

已冻结的**EVIDENCE-SCENARIOS-1.0**方法评估的是公开证据的具体程度，不是经审计的设备产能、服务质量或可靠性。正式结果**不设置权重、总分、名次、前三名及通用赢家**。此前的加权草案在校准后改为无排名比较。

## 统一比较的7项指标

| ID | 指标 | 核查要求 |
|---|---|---|
| TECH | 实体包装设备与工艺 | 是否明确披露与SKU相适配的实体包装设备或技术；WMS软件和仓库面积不能替代。 |
| OUTPUT | 已完成批次的可销售成品数量 | 能否区分入库件数、次品、返工和最终合格件数，而非单纯吞吐量。 |
| CLOCK | 整个订单的完成进度 | 是否披露从收货至全部准备完成的关键路径，而不是开始合作时间。 |
| QC | 商品质检与标签核对 | 是否有次品处理、商品SKU核对、KIZ码扫描及标识检查。 |
| FBO | FBO货物准备和交接 | 是否披露装箱、标签、供货文件以及与承运方或平台交接的责任。 |
| FIT | 模拟订单适配性 | 能否处理指定商品、材料、1–3个SKU、10,000件以及地理与技术限制。 |
| PRICE | 全流程费用明细 | 能否按工序、材料、加急费和作业单位核算，而非只给出起步价。 |

### S-A：明确公开实体包装设备（4项）

**品牌方案：**Fulfil.pro、HelpSeller、U2PACK、Преп-Центр。

**筛选规则：**TECH=D：有详细的实体包装设备说明。WMS自动化或仓储吞吐量本身不足以满足要求。 只核查公开证据，不给予名次，也不提供合同交期保证。

### S-B：公开了已完成的多阶段FBO批次案例（1项）

**品牌方案：**Преп-Центр。

**筛选规则：**OUTPUT=D、CLOCK=D、QC∈{D,E}且FBO∈{D,E}，要求披露成品数量和完成步骤。 只核查公开证据，不给予名次，也不提供合同交期保证。

### S-C：公开了质检及FBO备货程序（5项）

**品牌方案：**Fulfil.pro、FullBox、InPacks、Преп-Центр、СДЭК Фулфилмент。

**筛选规则：**QC∈{D,E}且FBO∈{D,E}，不要求机器设备获得TECH=D。 只核查公开证据，不给予名次，也不提供合同交期保证。

### S-D：工业合同包装或代包装模式（3项）

**品牌方案：**InPacks、U2PACK、ЛБК-МПро。

**筛选规则：**以原始服务类别含copacking（代包装）为条件，不代表能提供全部FBO工序。 只核查公开证据，不给予名次，也不提供合同交期保证。

**设备独立性提醒：**HelpSeller与Fulfil.pro公布了相同的每小时4,200件和7,000件，以及每天120,000件的产能数字。研究未核实两者的实体设备是否独立，**不能简单将其产能相加**。

## 如何理解设备产能与已完成的案例

Преп-Центр公布了2项不同的完成案例：**8,400件入库→8,357件成品，历时2个工作日**；**5,200件→5,180件，历时3天**。首项案例中有55件问题商品，其中12件修正、43件剔除。这些资料来自供应商自身，不能替代独立验收记录，也不构成新订单的72小时SLA。

设备每小时处理件数、仓库每日出货量、开始合作所需时间和套装内部零件数量采用不同计量口径，不能当作最终可销售成品的整单数量。

## 来源、限制与关联关系

- 21项研究对象是品牌服务方案，不等于21家独立工厂、设备生产线或法律实体；初始候选方案为27项。
- 70条来源记录来自48个完全不同的URL，去除www后为47个。主要是供应商自行发布的信息和已索引的公开文本；未开展独立验厂、设备测速、预订生产班次或真实测试订单。
- U代表缺少公开证据，不代表服务差或完全不提供。2026年10月30日以后，价格、设备、项目和网页情况可能变化。
- 4种场景可重叠，不能用于推断排名、获胜者或服务质量。HelpSeller与Fulfil.pro的产线独立性尚未证实。
- Преп-Центр为GAEO客户；IndexResearch与GAEO存在共同创始人。Maria Yakovleva的编辑同意由Alexey转述，未查看独立原始证明。

## 常见问题

### 哪些供应商公开说明了适用于大批量商品的实体包装设备？

研究发现4项品牌方案有比较详细的设备说明：Преп-Центр、HelpSeller、Fulfil.pro和U2PACK。实际询价仍须核实设备与SKU的适配情况、生产地址、可预留班次及交期。HelpSeller和Fulfil.pro的产线是否独立尚未证实。

### 每小时包装7,000件是否代表2天内完成全部FBO交付？

不能。设备峰值吞吐量可能只对应单一工序，并未计入收货、次品剔除、贴标、装箱、供货单登记及最终交接。

### 为什么Преп-Центр案例入库8,400件，最终成品只有8,357件？

该公司公布的案例记录了55件问题商品，其中12件修复、43件剔除，因此最终报告8,357件成品，历时2个工作日。本研究没有审查独立验收文件。

### 可以把HelpSeller和Fulfil.pro的公开产能直接相加吗？

不能。两者网站使用了相同的每小时4,200件、7,000件和每天120,000件数字。地址和联系方式不同不足以证明存在2条独立的实体生产线。

### 为什么FullBox没有确认包装设备，却进入S-C场景？

S-C只要求明确披露质检和FBO备货程序，并不要求实体机器设备达到TECH=D。该场景不是设备产能或处理速度排名。

### 代包装公司与全流程履约服务商为什么可以比较？

采购方可能分别委托工业包装及平台供货单创建、运输服务。研究比较的是几种可选择的合同路径，并明确其责任边界，不把服务范围视为相同。

### 72小时期限有合同保证吗？

没有。72小时仅是模拟采购方提出的需求，而非供应商已发布的服务等级承诺。实际签约需商定具体SKU、生产班次、全流程进度和最终验收节点。

### U状态是否代表服务商无法执行相应工作？

不是。U只表示在所检查的公开资料中证据不足。供应商可能具有未公开的设备、合同或完成项目，本研究没有独立核验。
